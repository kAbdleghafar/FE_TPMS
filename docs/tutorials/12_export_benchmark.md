# Tutorial 12: Exporting to Abaqus/CalculiX and benchmarking

**Goal.** Write the same discrete problem as an Abaqus and a CalculiX deck, compare the
solutions field by field, and quantify mesh convergence. About 20 seconds (CalculiX optional).

**You will learn**
* `write_inp` with its dialects;
* `compare` and `gci`.

## Step 1: a model to export

```python
import numpy as np
import tpmsfem as tf
from tpmsfem.fem.materials import TI6AL4V_LPBF
from tpmsfem.geometry import TPMS, lattice_cube
from tpmsfem.mesh import voxelize

mesh = voxelize(lattice_cube(TPMS("gyroid", cell_size=4.0, density=0.35), 4.0, plate=0.5), (0, 0, 0), (4, 4, 4), 0.4)
md = tf.SolidModel(mesh, TI6AL4V_LPBF.elastic())
z = mesh.points[:, 2]
top = np.flatnonzero(z > 4 - 1e-9)
md.fix(np.flatnonzero(z < 1e-9))
md.fix(top, (0, 1), 0.0)
md.fix(top, (2,), -0.004)
md.solve()
print(f"{md.n_nodes} nodes; top reaction {-md.reactions()[top, 2].sum():.1f} N")
```

Output (from the test run):

```text
1053 nodes; top reaction 278.8 N
```

## Step 2: write the decks

Nodes, elements, constraints, consistent loads, eigenstrains and AM layer steps (element
birth) are all written, so the commercial solver solves exactly the same problem.

```python
from tpmsfem.io.abaqus import write_inp

deck_abq = write_inp(md, "lattice_abaqus.inp", dialect="abaqus", title="TPMSsuite export")
deck_ccx = write_inp(md, "lattice_ccx.inp", dialect="calculix")
print(deck_abq, deck_ccx)
print(open(deck_ccx).read().splitlines()[:6])
```

Output (from the test run):

```text
lattice_abaqus.inp lattice_ccx.inp
['*HEADING', 'tpmsfem export', '** generated by tpmsfem; units: mm, N, MPa', '*NODE, NSET=NALL', '1, 0.000000000e+00, 0.000000000e+00, 0.000000000e+00', '2, 0.000000000e+00, 0.000000000e+00, 4.000000000e-01']
```

## Step 3: run CalculiX and compare (optional)

<!-- not run: needs the CalculiX executable ccx -->
```python
from tpmsfem.bench.compare import compare
from tpmsfem.io.calculix import frd_field, read_dat_stress, read_frd, run_ccx

r = run_ccx(deck_ccx, threads=4)
U_ref = frd_field(read_frd(r["frd"]), "DISP", md.n_nodes)
S_ref = read_dat_stress(r["dat"], md.ne, md.nq).mean(axis=1)
print(compare(md.displacement(), md.stress().mean(axis=1), U_ref, S_ref, active=md.active_host))
```

For Abaqus, run the deck and read it back with `tpmsfem compare ours.npz --abaqus prefix`
(Tutorial 23); [benchmarking.md](../benchmarking.md) describes the workflow.

## Step 4: grid convergence

```python
from tpmsfem.bench.metrics import gci

print(gci(f1=10_310.0, f2=10_520.0, f3=10_960.0, r=1.5))    # fine, medium, coarse results
```

Output (from the test run):

```text
{'p': 1.824243766981597, 'f_exact': 10118.260869565218, 'gci_fine': 0.023246742293256857}
```

The observed order, the extrapolated value and the GCI (an uncertainty band on the fine
result) come back; Tutorial 4 computes them for a real lattice.
